# Product Roadmap

## Current Version: v0.2.1

Local-first quantitative factor research workbench with browser UI.

## v0.3 (Planned)

```
- Scheduled research tasks
- Project templates
- Run result comparison
- Factor version management
- Incremental data updates
- Extended research terminal capabilities (Value Research, Market Intelligence)
```

## v0.4 (Future)

```
- Local desktop installer (.msi/.exe)
- Plugin system
- More data adapters
- Research notebook export
```

## v0.5 (Future)

```
- Team server mode
- User authentication
- Permission management
- Project sharing
```

## v1.0 Candidate

```
- Stable plugin API
- Long-term data governance
- Complete upgrade mechanism
- Optional commercial support
```

## Out of Scope

The following are NOT planned for the open-source product:
- Payment processing
- Multi-tenant cloud hosting
- Real-time trading execution
- Brokerage API integration

These may be evaluated in a separate commercial phase.
